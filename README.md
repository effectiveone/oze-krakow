# OZE Kraków

Lokalny portal informacyjny o odnawialnych źródłach energii w Krakowie i Małopolsce.

## Stack
- Astro 4.x (static output)
- Vanilla CSS (forest green minimal theme)
- Cloudflare Pages

## Uruchomienie lokalne
```bash
npm install
npm run dev
```

## Deploy
Cloudflare Pages: build command `npm run build`, publish directory `dist`
